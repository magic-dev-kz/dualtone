# 🎨 DualTone

Generate accessible light & dark color palettes in one click.

**[Try it →](https://magic-dev-kz.github.io/dualtone/)**

## Features
- OKLCH-based palette generation for perceptually uniform colors
- Automatic WCAG contrast fixes — never ship inaccessible colors
- Color-blind simulation preview (protanopia, deuteranopia, tritanopia)
- Export to CSS custom properties or Tailwind config
- Color harmony suggestions (complementary, analogous, triadic…)
- Dark / light mode toggle

## Why DualTone?
Designers and front-end developers spend hours hand-tuning palettes for accessibility and dark mode. DualTone generates both themes at once, auto-fixes contrast issues, and exports production-ready code — so you ship beautiful, accessible UI faster.

## Tech
- Single HTML file — nothing to install
- Works offline (PWA)
- No accounts, no tracking
- Your data stays in your browser (localStorage)
- Free forever
